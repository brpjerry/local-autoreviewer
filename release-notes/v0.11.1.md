- **Simplest fix first:** the review prompt's "Proposed changes" section, which follow-ups use too, now asks for the simplest fix that solves the problem: concise, readable code in the style of the code around it. Reviewers should prefer changing or removing code to adding it, fix a problem once where it starts rather than guarding each place it shows up, reuse the project's helpers, and leave out checks, options, helpers, layers and comments the fix doesn't need. A reviewer whose only fix adds a lot of code says so, and describes a simpler approach if there is one. The method's self-check of proposed edits also asks whether a smaller fix does the same.
