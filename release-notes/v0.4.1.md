Fixes how a nit's proposed change is shown in the review.

- **Nits with a proposed change:** the diff's lines weren't indented with the rest of the nit, so GitHub ended the list item at the first of them. The diff showed up empty, its lines as stray bullet points, and the nits after it as raw Markdown in a code block. Each line of the diff is now indented, as it already was for findings. This had been the case since 0.1.1.
