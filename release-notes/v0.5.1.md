Keeps the PR description a review saw, and replays with it.

- **Kept description:** housekeeping removes a job's checkout and context after `retain_jobs`. It now keeps the context's `pr.json` in the job's `out/` first. That's the PR's title, description and refs as that review saw them. The copy is written whole or not at all, and if it fails, the context stays until a later housekeeping manages it.
- **`tools/replay`:** a replay took the PR's current title and description from GitHub. A description updated after the reviewed commit can describe the fixes the review prompted. Replaying upscale-relay-android#64 that way, both reviewers proposed exactly the fixes the description listed. The replay now uses the description the service reviewed the commit with, from the first job of that commit that kept it. A later rerun may have read a description edited since. `--live-description` uses the current one. The replay prints which one it used.
