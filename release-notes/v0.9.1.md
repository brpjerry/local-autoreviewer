The first release with 0.9.0's changes: any number of reviewers of each type, each with its own model (see [the 0.9.0 notes](v0.9.0.md)).

- **Release fix:** 0.9.0's package build failed in `check()`, so it was never released. Two of its new worker tests started a review thread and joined it in a cleanup. unittest runs `tearDown`, which deletes the test's state directory, before cleanups, so the review could still be writing there when the directory went. Both tests now join their threads in the test itself. The service is unchanged from 0.9.0.
