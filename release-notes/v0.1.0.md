First release.

- Polls the GitHub repos you configure every 2 minutes. When you open or update one of your own pull requests, Claude Code and Codex each review it, and each review is posted as a comment review pinned to the reviewed commit. A burst of pushes produces one review, and a push during a review cancels it in favour of the new commit.
- Uses your local `claude` and `codex` logins, so reviews run on your subscriptions rather than API credits.
- Claude can only read files (no command execution), confined to the checkout. Codex runs in its read-only sandbox. Neither loads your own hooks, plugins, MCP servers or instruction files, nor the PR's.
- Reviews are rebuilt from structured output and scanned for credentials before posting. Each agent run is memory-limited and killed whole on timeout or cancel.
- `local-autoreviewer resume <job>` continues a review's agent session interactively. `ask` sends it a single follow-up question.
- Ships as an Arch package with systemd user units. Nothing is enabled on install.
