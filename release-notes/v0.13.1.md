The worker picks up a replaced token without a restart.

- **Token files** (`github-token` and each `forgejo-tokens/<host>`) are read again whenever they change: replaced, rewritten or given a new mode. The new token is used for the next `gh` call, API request or `git` fetch, including those of a review already running, and the check that no review quotes a token knows the old token and the new one.
- **An unusable change**, such as a file left readable by others or still empty, keeps the token read before. The error is logged once, without the file's contents, and the worker switches once the file is fixed (a `chmod 600` is enough).
- **A token for another account** still needs a worker restart, because the account reviews post as is looked up at startup.
