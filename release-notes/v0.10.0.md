OpenCode reviews: a third agent type, for free OpenCode models and the OpenCode Go subscription.

- **OpenCode reviewers:** add an `[agents.opencode]` table with a `model` in OpenCode's `provider/model` form, such as `opencode/deepseek-v4.1-flash-free`, and list `"opencode"` in a repo's `agents`. As with the other types, `opencode-<name>` adds further reviewers, each with its own model; `effort` is appended as the model's variant (`provider/model#high`). Their reviews are posted with the others as one.
- **Locked down like the others:** opencode runs `opencode run --standalone --agent review --format json` with a config set in code. Its permission rules deny every tool, then allow only `read`, `grep` and `glob`, with reads outside the checkout only in the context directory: no shell, no edits, no web. Skills, plugins, MCP servers and web search are denied by policy as well. Project config and Claude Code compatibility are off, so neither your opencode setup nor the PR's `AGENTS.md`, `opencode.json` or `.opencode/` load, and the checkout drops `opencode.json`, `opencode.jsonc` and `.opencode/` along with the other agent files. `--standalone` keeps the review off opencode's background service.
- **A home of its own:** reviews keep opencode's config, data and caches in `~/.local/state/local-autoreviewer/opencode-home/`. Free models need no login. For OpenCode Go, run `local-autoreviewer opencode-login` and paste your Go API key. `doctor` checks that the configured model is available there.
- **Structured output from the prompt:** `opencode run` has no output-schema flag, so the schema goes in the prompt and the review is the JSON object in the final message, alone, fenced or after a sentence. A final message that holds no JSON, doesn't validate or was cut off at the output limit is retried like a failed review; a free model's usage limit defers the review without using a retry.
- **Credentials:** the scan before posting also looks for the logins in opencode's databases, yours and the reviews'.
- **`tools/replay`** links the reviews' opencode home as it does Codex's.
